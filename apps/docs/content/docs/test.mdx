# PromptUpdateDialog

可选更新场景的弹窗：展示版本、release notes，用户可「稍后」或「立即更新」。
下面是由 mock adapter 驱动的实时预览，走完 `idle → checking → available → downloading → ready`。

<ComponentPreview
  name="prompt-update-dialog"
  add="npx shadcn@latest add @swarmhive/prompt-update-dialog"
  code={`import { useState } from "react";
import { UpdateProvider } from "@/components/update-provider";
import { PromptUpdateDialog } from "@/components/prompt-update-dialog";

export function App() {
  const [open, setOpen] = useState(true);
  return (
    <UpdateProvider>
      <PromptUpdateDialog open={open} onOpenChange={setOpen} currentVersion="1.0.0" />
    </UpdateProvider>
  );
}`}
/>
