设置页的「软件更新」区块（纯 RN 原语：View / Text / Pressable）。含检查 / 下载 / 安装按钮 +
状态文本 + 自绘进度条 + 错误重试，常驻可见（非弹窗）。下载完成后 auto-install。

## 安装

```bash
npx shadcn@latest add @swarmhive-rn/update-settings-section
```

## 用法

放进你的设置页即可，状态/按钮由 `useUpdate()` 自动驱动：

```tsx
import { UpdateSettingsSection } from "@/components/update-settings-section";

function SettingsScreen() {
  return (
    <ScrollView>
      {/* 其他设置项 */}
      <UpdateSettingsSection locale="zh-CN" currentVersion="1.0.0" />
    </ScrollView>
  );
}
```

需在 `<UpdateProvider>`（`@swarmhive-rn/update-provider`）内使用。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `locale` | `"en" \| "zh-CN"` | 文案预设，缺省 `en`。 |
| `texts` | `Partial<UpdateTexts>` | 覆盖个别词条。 |
| `currentVersion` | `string` | 当前版本，显示在区块内。 |
