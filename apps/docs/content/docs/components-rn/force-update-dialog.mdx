强制更新（`upgradeType: "force"`）的 React Native 弹窗。`status` 为 `force-required` /
`downloading` / `ready` 时常驻、不渲染「稍后」按钮（软强制）。RN 的真正「继续劝」靠
`<UpdateProvider>` 的 AppState 回前台复核兜底——系统安装确认框的取消由 system_server 渲染，app 无法屏蔽。

## 安装

```bash
npx shadcn@latest add @swarmhive-rn/force-update-dialog
```

## 用法

无 `open` prop——可见性完全由 `status` 驱动（force-required / downloading / ready 时显示）：

```tsx
import { ForceUpdateDialog } from "@/components/force-update-dialog";

function App() {
  return (
    <>
      {/* 你的内容 */}
      <ForceUpdateDialog locale="zh-CN" currentVersion="1.0.0" />
    </>
  );
}
```

需在 `<UpdateProvider>`（`@swarmhive-rn/update-provider`）内使用。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `locale` | `"en" \| "zh-CN"` | 文案预设，缺省 `en`。 |
| `texts` | `Partial<UpdateTexts>` | 覆盖个别词条。 |
| `currentVersion` | `string` | 当前版本，用于描述文案。 |
