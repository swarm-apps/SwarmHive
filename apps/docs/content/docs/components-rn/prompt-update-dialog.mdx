可选更新（`upgradeType: "prompt"`）场景的 React Native 弹窗，纯 `react-native` 原语
（`Modal` / `View` / `Text` / `Pressable`）。展示新版本与 release notes，提供「稍后提醒」与
「立即更新」；下载中内嵌自绘进度条，下载完成后自动拉起系统安装器。

## 安装

```bash
npx shadcn@latest add @swarmhive-rn/prompt-update-dialog
```

## 用法

弹窗的开关由你控制（`open` / `onOpenChange`），内容与行为由 `useUpdate()` 自动驱动：

```tsx
import { useEffect, useState } from "react";
import { useUpdate } from "@/hooks/use-update";
import { PromptUpdateDialog } from "@/components/prompt-update-dialog";

function UpdateGate() {
  const { status } = useUpdate();
  const [open, setOpen] = useState(false);
  // 有可选更新时打开弹窗
  useEffect(() => {
    if (status === "available") setOpen(true);
  }, [status]);
  return <PromptUpdateDialog open={open} onOpenChange={setOpen} locale="zh-CN" currentVersion="1.0.0" />;
}
```

需在 `<UpdateProvider>` 内使用（`@swarmhive-rn/update-provider`）。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `open` | `boolean` | 弹窗开关（由你控制）。 |
| `onOpenChange` | `(open: boolean) => void` | 开关回调；「稍后」会 `postpone()` 并关闭。 |
| `locale` | `"en" \| "zh-CN"` | 文案预设，缺省 `en`。 |
| `texts` | `Partial<UpdateTexts>` | 覆盖个别词条。 |
| `releaseNotesRenderer` | `(notes: string) => ReactNode` | 自定义 release notes 渲染（如接 Markdown）；缺省纯文本。 |
| `currentVersion` | `string` | 当前版本，用于描述文案。 |
