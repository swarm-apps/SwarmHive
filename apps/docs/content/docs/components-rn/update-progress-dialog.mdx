独立的下载进度弹窗（纯 RN 原语，自绘进度条）。缺省按 `status` 自动显示：`downloading` /
`ready` 时可见，`open` 可手动覆盖。`ready` 态显示「系统弹窗确认中…」（install 已 handoff 给系统安装器）。

## 安装

```bash
npx shadcn@latest add @swarmhive-rn/update-progress-dialog
```

## 用法

缺省自动显示（下载中/就绪）；无需手动控制开关：

```tsx
import { UpdateProgressDialog } from "@/components/update-progress-dialog";

function App() {
  return (
    <>
      {/* 你的内容 */}
      <UpdateProgressDialog locale="zh-CN" />
    </>
  );
}
```

需在 `<UpdateProvider>`（`@swarmhive-rn/update-provider`）内使用。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `locale` | `"en" \| "zh-CN"` | 文案预设，缺省 `en`。 |
| `texts` | `Partial<UpdateTexts>` | 覆盖个别词条。 |
| `open` | `boolean` | 手动覆盖可见性；缺省按 `status` 自动（downloading / ready 显示）。 |
