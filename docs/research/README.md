## 写作约定

- 每篇文档顶部标注调研日期，便于判断是否过期。
- 引用外部链接使用 markdown 形式，方便点击核对。
- 调研结论可以作为 `docs/` 设计文档的引用源，但不直接写入设计文档；设计文档保持"我们决定怎么做"的视角。
